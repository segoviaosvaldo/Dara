          Configuración

          Sesión

          1) Conexión con Google Sheet

          Tu planilla es la única fuente de datos: la app trae todo de ahí al abrir, y guarda ahí mismo cada cambio, al toque — ya no queda nada guardado en el teléfono.

          2) Pedidos

          Se usa como valor inicial del tipo de cambio cada vez que abrís "Nuevo pedido", para no tener que buscarlo de nuevo cada vez.

          Ver cotización de hoy ↗
          2b) Clientas

          Si un pedido ya llegó y la clienta no terminó de pagar en este tiempo, aparece automáticamente como deudora dentro de "Clientas" (con la etiqueta "Pedidos"), hasta que se salde.

          2c) Ventas

          Cuando marques una venta como facturada por primera vez, se usa este número. Las siguientes facturas se numeran solas, siempre a partir de la última que marcaste.

          3) Mensajes de WhatsApp

          Recordatorio de saldo (ficha de clienta). Podés usar (nombre), (monto) y (motivo).

          Aviso de pedido llegado (ficha de pedido). Podés usar (nombre), (detalle), (saldo) y (total).

          Aviso de pedido listo para retirar (ya pagó todo). Podés usar (nombre), (detalle) y (total).

          4) PINs de acceso

          Hay dos usuarios, Administrador y Auxiliar. Cada uno entra con su PIN y la app anota quién cargó cada cosa. Valen para todos los dispositivos conectados a la misma planilla.

          5) Respaldo manual (por las dudas)

          Ahora todo se guarda directo en tu planilla, así que esto ya no hace falta para el día a día. Sirve solo como copia extra, o para restaurar datos a mano si alguna vez hace falta.
